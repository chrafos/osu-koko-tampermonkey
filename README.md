# osu-koko-tampermonkey
inspired from osu!koko is that's a chrome extension for download beatmaps automatically, rewritten in so compatible with tampermonkey

## How to install
1. Ensure you have Tampermonkey/Greasemonkey installed and enabled. 
1. Go to https://github.com/chrafos/osu-koko-tampermonkey/raw/main/OsuKokoTampermonkey.min.js. Tampermonkey/Greasemonkey will automatically open a tab, prompting you to install the userscript. Install it.
1. On Chromium browsers, userscripts may not run properly without enabling Developer Mode. If necessary, enable Developer Mode for your browser (for Tampermonkey users, see https://www.tampermonkey.net/faq.php?locale=en#Q209)
